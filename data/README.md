# Alpha60 2026 data

This October update covers 77 media objects with an inclusive cutoff of
2026-10-02. Each object retains its actual available sample dates. See the
[media-object listing](txt/year-2026-0-media-objects.txt) and each object's
coverage report for dates, gaps, and sampling limits.

The JSON directory contains cumulative and weekly aggregates, per-Day swarm
aggregates, the cumulative IP swarm, and BTIH media-object metadata. Compressed
GeoJSON is organized into cumulative, weekly, and Day directories. Day indices
refer to each object's original sample origin; unavailable observations are
reported as gaps rather than invented zero-activity samples.

Coverage evidence, Day stream and product receipts, and validated publication
receipts are in the corresponding year-2026 directories under `txt`.
BTIH file-size CSVs are under `csv/bytes`. The itemized results pages link the
graphs, maps, source data, and individual coverage evidence.

[Canonical media-object metadata](https://github.com/alpha60-devops/alpha60-swarm-metadata/tree/main/metadata)
provides identity and collection scope.

The 16 regenerated October objects use corrected geographic grouping that
preserves the full first weighted contribution. The 61 retained objects
preserve their historic measurements; their pages identify the earlier
grouping error and its incomplete regional percentages. Compare geographic
summaries with that calculation difference in mind. Source revisions and
artifact identities remain recorded in each publication receipt.
